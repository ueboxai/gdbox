# 第一次打开

十来分钟配好模型、接上项目，然后让 Agent 在你自己的项目里做第一件事。

装应用见[安装与更新](/guide/install)。第一次启动会让你选一次界面语言，之后可在 设置 → 常规 → 语言 改。

## 配好模型

必填项只有一个：**设置 → 模型 → 默认模型 → 对话**。

1. **设置 → 模型 → 添加服务商**，填 API 密钥。密钥加密存在本机，不经中转服务。手里有 ChatGPT、Kimi 等会员的话，也可以在同一个目录的「订阅服务」里用账号登录，见[订阅服务](/guide/ai-setup#订阅服务)。
2. **设置 → 模型 → 默认模型**，把「对话」指向刚配好的模型。

其余角色（Agent、视觉、嵌入、生图、语音）等用到再配，每一项下方都标了不配会影响什么。

没有密钥也能开工：目录里「本机推理」一组（Ollama、LM Studio、llama.cpp）跑在你自己的机器上，不需要密钥。效果和速度取决于你的硬件，**模型必须支持工具调用**，否则操作不了项目。详见[配置模型](/guide/ai-setup)。

## 确认找到了 Godot

项目库上半部分「引擎版本」列出本机找到的 Godot 4。Windows 上会查 PATH、winget、scoop 和 Steam 的安装位置；其他系统只查 PATH 上的 `godot`。

显示「没有找到 Godot 4」时，点「添加 Godot」选 Godot 编辑器的可执行文件，或把可执行文件、所在文件夹拖进那块区域。macOS 上选 `Godot.app` 也行。

打开项目、试玩、Agent 检查项目，都用默认的那个 Godot。默认的也可以在 设置 → 项目库 → Godot 编辑器 里指定。

## 接上你的项目

1. **项目库 →「我的项目」旁的 `+`（导入或新建项目）**。弹窗里列出 Godot 项目管理器里登记过的项目，点一个就导入；列表里没有的，点「选择 project.godot 文件」，或把 `project.godot` 或项目目录直接拖进项目库。盒子不会扫硬盘找项目。
2. 第一次导入时会问「给导入的项目装上 GDBox 插件？」。选「安装」，之后导入和打开项目时都会自动装上 GDBox Link，见[连接 Godot 编辑器](/guide/plugin)。
3. **双击项目卡片或右键「打开项目」**，用默认的 Godot 打开编辑器。

没有现成的项目时，在同一个弹窗里点「新建空项目」，选一个空文件夹。

在 Godot 里打开过、装了 GDBox Link 的项目，编辑器连上盒子时会自动登记进项目库。

## 发第一条消息

**侧边栏 → AI 对话**，说清楚你要什么。几个够具体、一轮能看到结果的开头：

- 「这个项目的主场景里有哪些节点？脚本挂在哪几个上？」—— 纯只读，用来确认它读得到项目
- 「检查一下项目里有没有脚本报错，先给我清单，别动手」
- 「给主角加二段跳，改完试玩一下确认能跳两次」

默认档位是「自动批准」：Agent 自己动手，识别到风险操作时停下来问你。想让它只看不动，把档位调成「只读」。见[审批模式](/guide/assistant#审批模式)。

## 只想用素材管理

不配模型也能用，资产库是完整的独立工具：

1. **侧边栏 → 资产库**
2. **左上角库名 → 新建资产库**
3. 选模式：**引用原有文件** / **复制并归档**
4. 拖入文件或文件夹

两种模式的区别和取舍见[资产库](/guide/asset-library)。

## 它启动时做了什么

启动时，盒子会查找本机的 Godot 4，列在项目库上方，并恢复你上次所在的标签页（没有可恢复的就进项目库）。项目库里已装了 GDBox Link 的项目，插件版本和随包的不一致时会更新成随包的版本。

- 不扫描硬盘找项目，也没有账号校验。
- 开机自启默认关闭，要用的话在 设置 → 常规 打开。
- 网络动作只有一项：**如果这个安装包配置了更新源**，启动后静默查一次有没有新版本，之后每 4 小时再查一次，见[更新源](/guide/install#更新源)。没配更新源的构建一次都不发。
- 除此之外，只有你用 AI 功能（连你自己配的服务商）时才联网。

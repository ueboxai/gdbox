# 连接 Godot 编辑器

Agent 读写项目文件、检查报错、试玩和截图，都不需要编辑器开着。Godot 编辑器开着并连上盒子之后，Agent 还能看到你在编辑器里正在做什么，并替你操作编辑器。

连接靠装在项目里的插件 **GDBox Link**。

## 连上之后多了什么

| 能力           | 说明                                                       |
| -------------- | ---------------------------------------------------------- |
| 看选中的内容   | 编辑器里选中的节点和文件系统面板里选中的文件               |
| 看场景树       | 当前打开的场景的节点树                                     |
| 打开和选中     | 在编辑器里打开某个场景或资源，选中指定节点                 |
| 运行和停止     | 在编辑器里运行主场景或指定场景，停止运行                   |
| 保存全部       | 保存编辑器里打开的所有场景                                 |
| 重新加载       | Agent 改了磁盘上的场景文件后，让编辑器重新加载已打开的那个 |
| 重新扫描       | 让编辑器重新扫描项目文件                                   |

插件只回答盒子的请求，不会自己改项目。

Godot 4.4 及以上，文件系统面板的右键菜单里多一项「**添加到 GDBox 资产库**」，把选中的文件和文件夹导进资产库。

## 它怎么装上的

装的位置是 `<项目>/addons/gdbox_link/`，里面是 `plugin.cfg` 和两个 `.gd` 文件。不需要编译，任何 Godot 4 版本用同一份。

一次安装做两件事：

1. 把插件文件拷进项目的 `addons/gdbox_link/`。项目里已有的和随包的任何一个文件不同，就整份覆盖
2. 在 `project.godot` 的 `[editor_plugins]` 段里把 `res://addons/gdbox_link/plugin.cfg` 加进 `enabled`

第一次导入项目时，盒子问一次「给导入的项目装上 GDBox 插件？」：

- 选「**安装**」：给这次导入的项目装上，之后自动安装保持开启
- 选「**暂不安装**」或关掉弹窗：不装，以后也不再问。需要的项目从卡片右键 →「安装桥接插件」

自动安装开启时，触发时机有两个：

- **导入项目时**
- **从盒子打开项目时**（项目卡片、托盘「最近项目」）：先装好或更新，再启动编辑器

另外，**每次启动应用时**，项目库里已经装了插件的项目，`plugin.cfg` 里的版本号和随包的不一致就更新。这一步不看自动安装开没开，没装插件的项目不会被装上。

## 不想让它装

单个项目不想要：项目卡片右键 → **移除桥接插件**，在确认框里确认。这会删掉那个项目下的 `addons/gdbox_link`、从 `project.godot` 里摘掉它，并把这个项目记进一份**不再自动安装**的名单。

::: tip 为什么要用右键菜单移除
手动删除插件目录没用：盒子把「文件不存在」当作「需要安装」，下次从盒子打开项目时会装回来。从右键菜单移除才会写入名单，之后导入、打开、启动时的更新都会跳过这个项目。

想装回来就右键 →「安装桥接插件」，盒子会先把这个项目移出名单。
:::

## 确认连上了

插件在编辑器里主动连本机的 `ws://127.0.0.1:17870`，断了每 3 秒重连一次，不需要手动连接。

连上的项目，项目卡片上标「**已连接**」，侧边栏里属于这个项目的对话也标「已连接」。命令行里可以跑 `gdbox doctor`，它会列出项目库里有几个项目、几个 Godot 编辑器连着。

**项目开着却一直没有「已连接」**：

1. 项目卡片右键看菜单：显示「安装桥接插件」说明没装，点它装上
2. 装了还是没连上，到 Godot 的「项目设置 → 插件」里确认 GDBox Link 已启用
3. 主界面挂着「Godot 编辑器连接服务未能启动」横幅时，是盒子没能占用端口 `17870`。按横幅上的提示关掉占用端口的程序或别的 GDBox 窗口，点「重试」

## 导入项目时提示插件没装上

弹窗标题是「项目已导入，但 AI 连不上 Godot 编辑器」，正文写着盒子报的原因，例如没有写入权限、`project.godot` 读不出来。

主按钮是「**交给 AI 排查**」：点它会新开一条对话，把项目路径和失败原因交给 Agent 去查，能修的话它会直接修。也可以事后从项目卡片右键 →「安装桥接插件」。

从托盘打开项目时插件没装上，系统通知是「项目已打开，AI 连接失败」。

# 项目库

登记项目后，Agent 才能操作它。

项目库是侧边栏第一项，也是应用的默认页面。上半部分是**引擎版本**（本机的 Godot 4），下半部分是**我的项目**。

## 引擎版本

启动时，盒子会查找本机的 Godot 4。每个找到的可执行文件都会用 `--version` 跑一次，只列出能跑、版本是 4.x 的。

| 系统    | 自动查找的位置                                        |
| ------- | ----------------------------------------------------- |
| Windows | PATH 上的 `godot`、winget、scoop、Steam 的安装位置    |
| macOS   | PATH 上的 `godot`                                     |
| Linux   | PATH 上的 `godot`                                     |

同一个版本带的 `_console.exe` 不单独列出。

每张卡片上可以：

- **启动**：打开这个版本的 Godot 项目管理器，不带项目
- **设为默认 / 取消默认**：打开项目、运行游戏、Agent 检查和试玩项目，都用默认的那个。和 设置 → 项目库 → Godot 编辑器 是同一个设置。没设默认时自动查找
- **打开所在目录**：打开可执行文件所在的文件夹
- **移除**：只有手动添加的才能移除，只从列表移除，**不删除硬盘上的文件**

右上角「刷新」重新查找。

::: tip 没找到 Godot
显示「没有找到 Godot 4」时，点「添加 Godot」选 Godot 编辑器的可执行文件，或把可执行文件、所在文件夹**拖到引擎区域**。macOS 上选 `Godot.app` 也行。

选中的文件不是 Godot 4 时，提示「不是 Godot 4 可执行文件」，不会加进列表。
:::

查找出错时显示「查找 Godot 失败」，点「重试」。

## 导入项目

盒子不会扫描硬盘找项目，需要你指给它。导入只把路径登记到列表。

| 方式               | 操作                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------ |
| 拖入               | 把 `project.godot` 文件或项目目录拖到项目库页面                                            |
| 从 Godot 的名单选  | 点「我的项目」旁的 `+`，在列表里点项目；列表来自 Godot 项目管理器里登记过的项目，也可「全部导入」 |
| 手动选文件         | 在同一个窗口底部点「选择 project.godot 文件」                                              |
| 编辑器连上时自动登记 | 装了 GDBox Link 的项目在 Godot 里打开、连上盒子时，库里没有就自动登记                     |

拖入的目录里有多个项目时，会让你勾选要导入的项目。

批量导入后，提示按段拼成，例如「成功导入 3 个，2 个项目已在库中，1 个失败」。

导入时是否往项目里装 GDBox Link，见[连接 Godot 编辑器](/guide/plugin#它怎么装上的)。

### 导入到分组

先点中某个分组按钮，再导入，项目会直接进入该分组。

导入窗口的列表里，已经在库里的项目标「已导入」。选中了分组时，这些项目可以点击加入分组，不会重复登记。

## 新建项目

点「我的项目」旁的 `+`，在窗口底部点「**新建空项目**」，选一个空文件夹（或新建一个）。

盒子在里面写一份 `project.godot` 和一个 `icon.svg`，项目名取文件夹名，然后登记进项目库。文件夹里已经有东西时不会建，已有 `project.godot` 时提示你直接导入它。

## 项目卡片

双击卡片打开项目。卡片上标「已连接」表示这个项目的 Godot 编辑器已经连上盒子。

右键菜单：

| 菜单项                      | 说明                                                                               |
| --------------------------- | ---------------------------------------------------------------------------------- |
| 打开项目                    | 用默认的 Godot 打开编辑器                                                          |
| 运行游戏                    | 不开编辑器，直接把游戏开在窗口里，见下节                                           |
| 打开 C++ 项目               | 项目目录下有 `.sln`（Godot 的 C# 项目）时才出现，打开这个 `.sln`                   |
| 打开目录                    | 打开项目文件夹                                                                     |
| 置顶项目 / 取消置顶         | 固定在列表最前                                                                     |
| 重命名                      | **只改应用里显示的名字**，不改 `project.godot` 和磁盘上的文件                      |
| 自定义封面 / 恢复自动封面   | 换成自选图片，或恢复自动生成的封面                                                 |
| 安装桥接插件 / 移除桥接插件 | 安装或移除 GDBox Link，见[连接 Godot 编辑器](/guide/plugin)                        |
| 移出分组                    | 从分组里拿掉，项目仍在总列表。项目属于多个分组时，菜单项写明分组名                 |
| 移除项目                    | 从列表移除，**不删除项目文件**                                                     |

### 运行游戏

卡片上悬停出现的播放按钮、右键「运行游戏」、对话顶栏的「运行」，都是用默认的 Godot 直接运行项目的主场景，窗口开在屏幕上给你玩。

- 运行前会先导入项目里还没导入的资源，Agent 刚生成的图片和声音才能在游戏里看到
- 每个项目同时只开一局。再点一次是关掉这一局、按最新的文件重开
- 游戏的输出写进项目的 `.gdbox/tmp/play.log`，Agent 能读到你玩的时候报了什么错
- 游戏意外退出时提示「游戏意外退出」，带上日志里的报错

### 同名项目在不同路径

盒子按路径区分项目。两个项目同名但路径不同时，侧边栏的对话按路径分组显示。新建对话和选择项目时也带上路径。

## 分组

在空白处右键，选「创建分组」，或点分组按钮那一排最后的 `+`。分组显示为列表上方的一排筛选按钮：

| 按钮       | 显示内容               |
| ---------- | ---------------------- |
| **全部**   | 所有项目               |
| **未分组** | 没有归入任何分组的项目 |
| 分组名     | 该分组里的项目         |

把项目卡片**拖到分组按钮上**即可加入分组。要拿出来，用右键的「移出分组」。

解散分组时，分组本身被移除，其中的项目回到「未分组」，不会删除任何项目。

## 搜索与筛选

可以按项目名搜索，也可以按引擎版本筛选（包含「版本未知」）。版本取自 `project.godot` 里 `config/features` 写的版本号，例如 `4.4`。列表为空时，提示分三种：

| 提示                         | 含义                                       |
| ---------------------------- | ------------------------------------------ |
| 未找到匹配「{关键词}」的项目 | 搜索无结果，清空搜索框即可                 |
| 暂无「{版本}」的项目         | 版本筛选无结果，换一个版本或选「全部版本」 |
| 读取项目列表失败             | 本次读取失败，不代表没有项目。点「重试」   |

## 项目找不到时

打开一个已被删除或移走的项目时，弹窗标题是「找不到该项目」，正文给出登记的路径，并询问是否从列表移除这条记录。

点「刷新」时，如果发现一批这样的记录，会询问「是否将这些失效项目从列表中移除？」。该操作不会删除磁盘上的项目文件。没有失效记录时，提示「未发现失效项目记录」。

## 打开项目之后

**设置 → 项目库 → 打开项目后隐藏主界面**：开启后，从应用内打开项目时主界面收入托盘，后台任务继续运行。默认关闭。

## 插件没装上

导入项目时如果 GDBox Link 没装成功，会弹窗，标题是「**项目已导入，但 AI 连不上 Godot 编辑器**」，正文写明原因。

弹窗上的「**交给 AI 排查**」会新开一条对话，把项目路径和盒子报的原因交给助手，并列出该查的几处：`project.godot` 能否读取、里面声明的 Godot 版本、`addons/` 下有没有插件和 `plugin.cfg`、本机有没有对应版本的 Godot。

也可以事后在项目卡片右键里选「安装桥接插件」。

# GDBox 是什么

给一个目标，让 Agent 在你的 Godot 项目里把活干完。

GDBox 是一个**操作 Godot 项目的开源 AI Agent**。它是装在本机的桌面应用，给 Agent 配上工具、素材和权限，由 Agent 在真实的项目里读写场景和脚本、生成美术和音频素材、用 Godot 检查项目、自己试玩验证。改动直接落在项目里，不需要你复制代码再粘贴。

## 一轮任务长什么样

1. 你说一句：「给主角加二段跳」。
2. Agent 自己挑工具、一步步调用，每次调用的工具名、参数、返回值都摊在对话里。
3. 常规操作直接执行；碰到风险操作，它停下来等你批准。
4. 改完之后，它用 Godot 检查项目里的报错；要验证行为时，按设定的输入试玩几秒，看数值变化。盒子列出这一轮改了什么。

## Agent 靠什么干活

**模型** —— 你自己配一家服务商：国际厂商、国内厂商、订阅账号和套餐，以及 Ollama、LM Studio 这类本机推理；另有生图、语音、嵌入等专用接口。密钥加密存在本机，请求直达服务商，不经过我们的服务器。见[配置模型](/guide/ai-setup)。

**工具** —— 一次具体操作：读写一个场景或脚本、无头检查项目、按脚本输入试玩、截一张游戏画面、生成一张精灵图或一段音效。见 [Agent 能做什么](/guide/capabilities)。

**技能** —— 一组做法说明，规定某类任务的处理流程、已知陷阱和不适用的场景。你不需要指名，Agent 自己挑。见[工具、技能与权限](/guide/tools-and-skills)。

**权限** —— 权限档位决定它能动到哪儿、什么时候停下来问你，文件访问范围决定它能读写哪些目录。默认是「自动批准」：它自己动手，只在识别到风险操作时停下来。见[审批模式](/guide/assistant#审批模式)。

**核对** —— 干完之后有三层：本轮改动列出净结果和 diff；「审查」用只读工具重新查一遍；第三层要求 Agent 不凭记忆回答，每条都重新查询，再写出实际值。见[结果核对](/guide/assistant#结果核对-三层)。

## 不开编辑器也能干活

读写项目文件、检查报错、试玩和截图，Agent 都直接调用本机的 Godot 命令行完成，不需要 Godot 编辑器开着。

编辑器开着并装了 **GDBox Link** 插件时，Agent 还能看到编辑器里选中了什么、当前打开的场景树，并能打开场景、在编辑器里运行或停止游戏、保存全部。GDBox Link 是两个 GDScript 文件，拷进项目的 `addons/gdbox_link/` 就能用，不需要编译。

见[连接 Godot 编辑器](/guide/plugin)。

## 其余模块的位置

这些模块各自有完整的界面，可以单独使用。同时，它们给 Agent 提供作用目标、素材、参考资料和对外接口：

| 模块                   | 对 Agent 的作用                                                    |
| ---------------------- | ------------------------------------------------------------------ |
| **项目库**             | 登记 Godot 和项目，确定 Agent 的作用目标                           |
| **资产库**             | 素材来源。Agent 从中检索素材、复制进项目，也向其中写入生成结果     |
| **笔记与知识库**       | 资料来源。Agent 针对绑定的知识库检索材料，也把研究结果写回去       |
| **AI 创作、3D 查看器** | 素材生成与检查                                                     |
| **命令行、MCP**        | 把工具开放给脚本，以及 Codex、Claude Code、Cursor 这类外部客户端 |

## 开始之前

你需要自备两样东西：

- **Godot 4** —— GDBox 不含引擎。需要 Godot 4.x 的编辑器可执行文件。
- **模型 API 密钥** —— 用 AI 功能时需要。不想掏密钥就用 Ollama、LM Studio 跑本机模型。模型必须支持工具调用，否则操作不了项目。

不配模型也能用：资产库、笔记与知识库都是完整的独立工具。

### 平台

|         | 安装包   | 自动查找 Godot                              |
| ------- | -------- | ------------------------------------------- |
| Windows | ✅       | PATH、winget、scoop、Steam；也可以手动添加 |
| macOS   | 源码构建 | PATH 上的 `godot`；也可以手动添加 `Godot.app` |
| Linux   | 源码构建 | PATH 上的 `godot`；也可以手动添加         |

**Windows 是主力平台**，功能都在这上面验证。macOS 和 Linux 需要从源码构建（见[安装与更新](/guide/install#从源码构建)）。Linux 构建不含 `gdbox` 命令行。

## 开源版

本手册描述的是开源版，Apache-2.0 许可。

- **不需要账号。** 应用本身没有账号体系，也没有试用期。只有你给模型服务商选「用账号登录」时，才会打开浏览器授权。
- **本地功能不依赖网络。** 默认的联网只有检查更新，只查不下载，见[安装与更新](/guide/install)；自己打包且没填更新源的构建不发起更新请求。
- **模型请求直达服务商。** 密钥加密保存在本机，不经过我们的服务器。
- **其余联网由你开启。** 联网检索、生图、网盘、团队资产服务器、对象存储，用到才连。

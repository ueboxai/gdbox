# 文件都放在哪

要备份、要迁到新机器、要确认某样东西有没有离开过这台电脑 —— 都从这页查。

## 应用数据目录

设置、对话记录、技能、经验、日志都在系统的应用数据目录下，文件夹名是 `GDBox`：

| 系统    | 路径                                   |
| ------- | -------------------------------------- |
| Windows | `%APPDATA%\GDBox\`                     |
| macOS   | `~/Library/Application Support/GDBox/` |
| Linux   | `~/.config/GDBox/`                     |

主要内容：

| 文件 / 目录                             | 是什么                                                 |
| --------------------------------------- | ------------------------------------------------------ |
| `app-settings.json`                     | 应用设置，包括指定的 Godot 路径                        |
| `database/`                             | 项目库、资产库等的数据库                               |
| `models.json`                           | AI 服务商与模型配置（**不含密钥**）                    |
| `ai-provider-secrets.bin`               | 加密后的密钥                                           |
| `object-storage.json`                   | 对象存储的连接配置（**不含密钥**）                     |
| `object-storage-index.json`             | 传到对象存储的文件登记                                 |
| `instructions.md`                       | 给助手的常驻说明                                       |
| `skills/`                               | 技能目录                                               |
| `disabled-skills.json`                  | 关掉了哪些技能                                         |
| `plugins/`、`disabled-plugins.json`     | 插件                                                   |
| `mcp.json`                              | 接入的第三方 MCP 服务                                  |
| `mcp-server.json`                       | 对外开放的 MCP 服务配置，`gdbox` 命令行也读它          |
| `agent-v3-sessions/`                    | Agent 的执行记录，每条对话一份                         |
| `chat-history/`                         | 对话历史：`sessions/` 下一条对话一个文件，外加一份索引 |
| `experience/`                           | 经验库的通用层（所有项目共用）                         |
| `regression/`                           | 各项目的回归用例，每个项目一个子目录                   |
| `team/`、`team-models/`                 | 团队模式：每次任务的工作区；各模型的入职检测结果和履历 |
| `list-thumbnails/`                      | 缩略图缓存                                             |
| `logs/`                                 | 日志。报问题时附上它                                   |
| `diagnostics/`、`diagnostics/recovery/` | 诊断与恢复数据                                         |
| `window-state.json`                     | 窗口位置与大小                                         |
| `chat-window-state.json`                | 独立对话窗口的位置与大小                               |
| `spotlight-position.json`               | 快捷提问窗口的位置                                     |

::: tip 界面上有直达按钮
技能目录、MCP 配置文件、AI 服务商配置、命令行程序位置，各自的设置页里都有「在文件夹中显示」或「打开位置」，不用自己照着路径找。
:::

## API 密钥

密钥**不在明文文件里**。

| 填法           | 存在哪                                                 |
| -------------- | ------------------------------------------------------ |
| 直接填写       | 加密保存在 `ai-provider-secrets.bin`，用系统的凭据存储 |
| 环境变量名     | 只存变量名，密钥不进应用的任何文件                     |
| `!` 开头的命令 | 只存命令，密钥不进应用的任何文件                       |

系统加密不可用时界面会提示「无法安全保存密钥」，这时候用后两种方式。

应用没有中转服务器，密钥只用于直接连接所配置的 API 地址。

## 素材位置

位置在建库时指定：

| 情况                  | 文件在哪                                 |
| --------------------- | ---------------------------------------- |
| 资产库 · 引用原有文件 | **保持原位**，应用只存索引               |
| 资产库 · 复制并归档   | 复制到建库时选的保存位置                 |
| 资产库 · 网络协作库   | 共享盘或服务器上，本地只有缓存和连接记录 |
| AI 创作生成的图和模型 | AIGC 资产库                              |

::: tip 数据库只是索引
用户创作的东西，唯一真相源是磁盘上的文件。库里的数据库是可以删掉重建的索引层 —— 这也是「拷得走、备份得到、换台机器还在」的前提。
:::

## 项目和 Godot

项目库的「导入」只登记路径，「移除」只从列表中删除记录。盒子自身写入项目目录的内容如下：

| 位置                    | 内容                                                                                                                       |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `addons/gdbox_link/`    | 编辑器插件；同时在 `project.godot` 的 `[editor_plugins]` 里启用它。可以按项目移除，见[连接 Godot 编辑器](/guide/plugin) |
| `.gdbox/experience/`    | 在这个项目里踩过又解决的问题（经验库的项目层）                                                                             |
| `.gdbox/skills/`        | 这个项目自带的技能                                                                                                         |
| `.gdbox/snapshots/`     | 团队模式的项目快照，一个独立的 git 仓库，不碰项目自己的 git                                                                |
| `.gdbox/tmp/`           | 临时文件：检查和试玩用的运行脚本、截图、「运行游戏」的日志 `play.log`                                                      |

`.gdbox/` 里放了一个 `.gdignore`，Godot 不会把它当项目资源导入。整个 `.gdbox/` 删掉不影响项目本身。

Agent 按你的要求改场景、脚本、资源等内容，属于你让它做的编辑，不在此列；它们的权限见[工具、技能与权限](/guide/tools-and-skills)。

Godot 编辑器的导入缓存 `.godot/`，盒子不改。

盒子在后台跑 Godot（检查、试玩、截图）时用一份单独的 Godot 用户数据目录，放在系统临时目录的 `gdbox-godot-userdata` 下，不动你自己的 Godot 编辑器设置。「运行游戏」开给你玩的那一局除外，它和你在 Godot 里运行时用同一份存档。

## 录制文件

录屏产生的文件在录制库里管理（设置 → 录屏），详情里有「文件路径」和「在文件夹中显示」。

## 卸载之后

卸载不会删除应用数据目录。需要完全清除时手动删除该文件夹。

::: warning 该目录包含的内容
资产库索引、全部对话历史、自定义技能、加密后的密钥。
:::

## 备份与迁移

要换机器或留个底，复制两部分：

1. **应用数据目录**（上面那个文件夹）
2. **各资产库的目录**（建库时指定的位置）

装好应用把这两部分放回原位就能接着用。

### 迁移资产库的保存位置

不换机器、只想把资产库挪到别的磁盘时，不用手动复制：资产库页面左上角库名的列表里，右键那个资产库 →「更改保存位置」，选新位置后确认。盒子会把整个文件夹迁过去，迁移期间不要操作资产。网络协作库不适用。

::: warning 加密密钥可能不跨机器
`ai-provider-secrets.bin` 用的是系统凭据存储，换一台机器不一定解得开。新机器上重新填一次密钥即可，其他数据不受影响。
:::

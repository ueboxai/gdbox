# 资产库：导入到 Godot 项目

把库里的素材放进 Godot 项目。

Godot 项目就是一个普通文件夹，编辑器会扫描项目目录里的新文件并自动导入。所以导入到项目就是把文件复制进项目目录，不需要 Godot 编辑器开着。

## 基本流程

选中资产、多选或文件夹 → 右键「**导入到项目**」→ 点「选择文件夹」，选项目里的目标文件夹 → 「**复制到项目**」。

- 文件按原名复制。
- 选的是文件夹时，在目标下建一个同名文件夹，把这个文件夹里（含子文件夹）的资产都复制进去，不保留子文件夹层级。
- 目标里已有同名文件时跳过，不覆盖。项目里的文件可能已经改过，覆盖会丢掉这些改动。
- 弹窗会记住上次选的目标文件夹。

完成后提示复制了几个文件、跳过了几个同名文件；有文件复制失败时单独报失败数量，弹窗不关。

::: warning 只复制文件本身
源文件旁边的 `.import` 和 `.uid` 一起复制，导入设置和 uid 不变。场景（`.tscn`）和资源（`.tres`）引用的其他文件也不会一起复制，引用路径在新项目里不存在时，需要自己把依赖复制进来或修改引用。
:::

服务器资产库的文件不在本机，导入方式见[服务器资产库](/guide/asset-server#导入到-godot-项目)。

## 让助手导入

在 AI 对话里说要导入什么，例如「把素材库里那几张树的贴图放进项目的 res://art/trees」。助手先搜素材库，再用 `import_to_project` 复制文件。和界面导入的区别：

- 目标写成 `res://` 路径，不写时放进 `res://assets/library`。不能放进 `.godot/`，那是编辑器缓存。
- 源文件旁边的 `.import` 和 `.uid` 一起复制，导入设置和 uid 不变，引用它的场景不会找不到资源。
- 同名文件默认不覆盖，你明确要求覆盖时才覆盖。
- 复制的是 `.tscn` 或 `.tres` 时，会检查它引用的 `res://` 文件在目标项目里是否存在，不存在的在结果里列出来。
- Godot 编辑器通过 GDBox 插件连着时，复制完让编辑器重新扫描，新文件马上出现在「文件系统」面板。没连时等编辑器下次扫描。

助手需要知道往哪个项目里放。对话还没绑定项目时，它会问你。

# 助手能做什么

按领域列出助手能做什么，以及每个领域做不到什么。边界写在每节末尾的提示框里。

助手的能力由两部分构成：

- **工具** —— 一次具体操作，例如读一个场景文件、无头跑一遍项目查错、生成一套精灵。内置几十个，实际给到模型的数量随对话状态、工具开关和[工具搜索](/guide/tools-and-skills#工具搜索-beta)变化。
- **技能** —— 一组做法说明，规定某类任务的处理流程、已知陷阱和不适用的场景。内置 17 个。

不需要指名工具或技能，助手按任务内容选。

收紧可操作范围见[工具、技能与权限](/guide/tools-and-skills)，一轮任务怎么推进见[助手是怎么干活的](/guide/agent-loop)。

## 先看前提

大部分活不需要开 Godot 编辑器。场景、脚本、资源都是文本文件，助手直接读写；检查和试玩由盒子自己起一个无头 Godot 来跑。

| 类别                                       | 需要编辑器 | 说明                                                                            |
| ------------------------------------------ | ---------- | ------------------------------------------------------------------------------- |
| 读写场景、脚本、资源、`project.godot`      | 否         | 直接改项目里的文本文件                                                          |
| 检查、试玩、截图                           | 否         | 需要 GDBox 找得到 Godot 4，在 **设置 → 项目 → Godot 编辑器** 里看或指定        |
| 开一个游戏窗口给你玩                       | 否         | 同上                                                                            |
| 看编辑器里的场景树和选中、在编辑器里运行   | 是         | 需要 GDBox Link 连着，见[连接 Godot 编辑器](/guide/plugin)                      |
| 生成精灵、瓦片、音效、音乐、配音           | 否         | 直接写进项目的 `res://assets/gen/`；除本机合成的音效外，按次向服务商计费         |
| 资产库、笔记与知识库                       | 否         | 纯本地                                                                          |
| 本机文件、命令行                           | 否         | 受文件访问范围限制                                                              |
| 联网检索、浏览器                           | 否         |                                                                                 |
| 生图、生视频、生 3D                        | 否         | 按次向所配置的服务商计费                                                        |

::: tip 编辑器没连时它会明说
`editor_*` 这几个工具只在编辑器连着时出现在助手手上。没连时它照样读写项目、跑检查和试玩；需要编辑器的那部分会告诉你，不会编造一个看起来成功的结果。编辑器在一轮中途连上，这些工具当场出现。
:::

::: tip 找不到 Godot
检查、试玩、截图都要用到本机的 Godot 4。找不到时助手会让你去 **设置 → 项目** 指定 Godot 编辑器的位置，不会改用别的办法绕过去。
:::

## Godot 项目

### 场景、脚本和资源

`.tscn`、`.tres`、`.gd`、`.gdshader` 和 `project.godot` 都是文本，助手直接读、写、改，包括节点树、属性、信号连接、输入映射、脚本逻辑。

- 不碰 `.godot/` 目录，那是编辑器的缓存，会自动重建。
- 改场景和资源时保留现有的 `uid://` 引用，不手写新的 uid。
- 路径不确定时先列目录或搜索，不凭记忆拼 `res://` 路径。
- 编辑器连着时，改完一个场景或资源，编辑器里开着的那份会从磁盘重新加载，免得你一保存就把改动盖掉。
- 你在编辑器里开着、还没保存的场景，助手改之前应先调用 `editor_save_all` 存盘。

助手知道项目声明的 Godot 版本。Godot 4.4 之后有一批改了默认值或写法的 API，它会按项目版本拿到这份差异清单；检查报错时，如果报错和某条版本差异对得上，也会附上提示。

### 检查：`godot_check`

导入项目，加载项目里的每一个脚本（包括还没被任何场景用到的），再无头运行若干帧（默认 120 帧，60 fps），报告脚本错误和引擎错误。

助手每次改完脚本或场景都要跑一遍，有报错不说做完。

### 试玩：`godot_run`

带着脚本化的输入把游戏跑几秒（默认 3 秒，上限 60 秒），报告指定的值随时间怎么变。用来验证行为，不往项目里写临时测试场景。

| 能做         | 说明                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------ |
| **模拟输入** | 按 InputMap 里的动作、按某个键、在坐标或某个节点上点鼠标、在两点之间拖拽，按时间表执行                 |
| **盯数值**   | 节点属性、脚本变量、无参数的 `get_` / `is_` / `has_` 方法，例如 `Player:position:y`、`Player:is_on_floor()` |
| **批量统计** | 对一组节点求 count / min / max / mean / sum / changed，按分组、按类或按子节点圈定                      |
| **自动报异常** | 位置或速度变成 NaN、inf，或节点飞出几百万像素外                                                      |
| **截图**     | 在指定时刻截几张图                                                                                     |

运行期间的错误一并报告。

### 截图：`godot_screenshot`

在屏幕外跑若干帧（默认 30 帧），返回最后一帧的画面。改了布局、美术、动画、界面这类看得见的东西，助手要先看一眼再报告。

### 给你玩：`godot_play`

开一个游戏窗口让你自己玩。再开一次会替换正在跑的那个。启动后几秒内的报错会报回来；你玩的时候，完整日志持续写在 `.gdbox/tmp/play.log`。

### 你开着的编辑器

GDBox Link 连着时：

| 工具                          | 作用                                               |
| ----------------------------- | -------------------------------------------------- |
| `editor_scene_tree`           | 读当前打开场景的节点树、你选中了什么、游戏在不在跑 |
| `editor_play` / `editor_stop` | 在编辑器里运行 / 停止游戏，给你看                  |
| `editor_open_scene`           | 在编辑器里打开一个场景                             |
| `editor_select`               | 在编辑器里选中节点，指给你看                       |
| `editor_save_all`             | 保存编辑器里所有打开的场景                         |

你说「这个」「我选中的」时，助手按发送那一刻编辑器里的选中来理解；没选中会请你先选。

### 回放用例

`godot_run` 验证过的一段行为可以存成回放用例（`regression_add`）：一串输入加断言。盒子当场在项目上连跑两遍，两遍都过且结果一致才收下。之后用 `regression_run` 重跑，不调用模型；项目没变的用例直接沿用上次结果。团队模式里这些用例是交付的机器门，见 [AI 对话 · 团队模式](/guide/assistant#回放用例与冠军)。

::: warning 检查和试玩的边界

- **截图看对了只证明那一帧对。** 跑起来之后要一直成立的事（速度不失控、东西不掉出地面、该动的在动），要用 `godot_run` 盯数值，并且跑得够久。
- 截图依赖「允许编辑器截图」。关掉后 `godot_screenshot` 和 `godot_run` 的截图都不可用，助手只能靠读场景文件和数值确认。见[工具、技能与权限](/guide/tools-and-skills#全局-允许编辑器截图)。
- 当前模型看不了图时，截图工具照样能用、你能看到图，但助手看不到，它会直说并请你看。
- **不做画面质量和玩法判断。** 判位置、判数值、判有没有报错可以，判好不好看、好不好玩不行。
- 改 `project.godot` 里的版本号不等于升级。装另一个版本的 Godot 这类事助手做不了，它会直说。

:::

## 素材生产

生成的素材直接写成项目里能用的 Godot 资源，放在 `res://assets/gen/<类别>/`。同名重新生成会原地覆盖，旧文件备份到 `.gdbox/history/`；每次生成在 `.gdbox/generations.jsonl` 记一行。

| 工具               | 产出                                                                                                       |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| `gen_sprite`       | 用生图模型画 2D 动画角色或物体，写成透明底精灵表和 SpriteFrames（`.tres`，给 AnimatedSprite2D 用）          |
| `gen_sprite_video` | 用视频模型生成一段动作，抽帧抠底做成 SpriteFrames。帧多、动作连贯，但贵得多也慢得多，一次要几分钟         |
| `gen_tileset`      | 生成 TileMapLayer 用的瓦片图集和 TileSet，实心瓦片带整格碰撞                                              |
| `gen_sfx`          | 本机合成复古音效（离线、不花钱）；绑了「音效生成」模型并给了描述时改为 AI 生成                            |
| `gen_music`        | 生成背景音乐，默认裁成无缝循环的 WAV，导入后自动循环。要一到几分钟                                         |
| `gen_voice`        | 把台词逐条合成 WAV。文字、音色、演法都没变的台词跳过不重做                                                |
| `design_voice`     | 按文字描述给角色设计新音色，返回试听。只支持阿里云 Qwen-Audio 3.0 语音合成                                |
| `adopt_voice`      | 把试听过的音色定为角色的正式音色。每次都要你当场确认                                                      |
| `inspect_audio`    | 测量音频的时长、响度、削波、首尾静音、循环接缝。只读                                                       |
| `art_style`        | 读写项目的美术风格（风格词、像素风、帧高、瓦片尺寸、调色板、参考图），之后的精灵和瓦片自动套用           |

美术风格存在项目的 `.gdbox/style.json`，也可以存成跨项目的预设。

::: warning 素材的边界

- **助手听不见声音。** 它用 `inspect_audio` 量一遍，再请你在资产抽屉里试听。
- 生成花的是服务商额度。结果不满意时，助手先说明问题、给你选项，不自己决定重新生成；你明确说重来才重做。
- 生成的文件不再用脚本二次加工。

:::

### 生图、视频与 3D

- **生图** —— 概念图、贴图、海报、UI 草图、多版变体，支持参考图。产出保存进资产库。见 [AI 创作](/guide/aigc)。
- **视频** —— 生成视频片段（支持参考视频和参考音频），也能分析一段视频。
- **3D** —— 从文字或参考图生成 3D 模型，Tripo 生成的可以接着自动绑骨。见 [3D 生成与查看器](/guide/model3d)。

### AI 做 3D 资产（串联流程）

从一句描述或一张参考图出发，把上面几项串起来：

```
生图（概念图 + 互相一致的四视图）
   → image-to-3D（glb 底模）
      → 放进 Godot 项目，用一个包装场景修正缩放、朝向、原点和碰撞
         → Blender 修形（接了 Blender 时）
```

每一段结束后**对照参考图核对**再进入下一段。Blender 通过 [MCP](/guide/mcp#blender) 接入。

### 任务转视频

把当前这次对话和它的成果做成一段可继续编辑的本地视频（教程或宣传片），包含文案、分镜、配音和音乐。

## 应用自身

### 资产库

检索和整理素材库：查找资产、看全库分布、读写备注和标签、在文件夹之间移动、新建/重命名/删除文件夹、删除或恢复条目、切换保管库。

作用对象是**素材库**，不是 Godot 项目里的文件，两者是不同的东西。

把库里的资产放进项目用 `import_to_project`：连同 `.import`、`.uid` 旁挂文件一起拷，默认放到 `res://assets/library`，同名文件默认不覆盖；场景和资源引用的依赖在目标项目里没有时会列出来。

::: tip 搜索默认只看当前库
助手默认只搜当前活跃的保管库。要同时搜其他保管库，打开 设置 → 资产库 →「跨库搜索」。写入始终只发生在当前活跃的库；切换保管库会改变整个视图，助手会先问你，除非你点过「本对话内均允许」。
:::

### 笔记与知识库

读写笔记、把研究结果作为来源存进知识库、从绑定的知识库里检索材料。对话怎么绑定知识库见[笔记与知识库](/guide/notebook)。

### 项目库

列出「我的项目」里登记的 Godot 项目，把项目库整理成分组和置顶，把这条对话绑定到某个项目。

### 本机文件

列目录、按 glob 查找文件、搜索文件内容、读文本、图片和文档、写入和修改文件，以及在有 shell 的机器上执行命令。

受[文件访问范围](/guide/tools-and-skills#全局-文件访问范围)限制，敏感目录始终排除。你电脑上的文件大多没进版本控制，助手写之前要说清改哪个文件、改什么。

### 浏览器与联网

`web_search` 搜网页、`web_read` 读正文，都不开窗口、不需要审批。另外可以打开一个**你看得见、随时可以接管**的浏览器：

| 能做         | 说明                                                              |
| ------------ | ----------------------------------------------------------------- |
| **打开网址** | 只接受完整的 http/https；本机和局域网地址默认拒绝，可在设置里放开 |
| **读页面**   | 读过滤后的正文，或读一份带编号的可交互元素清单                    |
| **页内导航** | 后退、前进、刷新、滚动、跟随页面上已有的链接                      |
| **交互**     | 点按钮、填普通文本、选下拉项                                      |
| **截图**     | 截当前可见区域                                                    |

显示位置和局域网访问都在 设置 → AI 助手，见[工具、技能与权限](/guide/tools-and-skills#全局-浏览器)。

::: danger 浏览器里的三条红线

- **密码、验证码、支付和文件选择一律拒绝**，这些请你自己来。
- **每一次点击和输入都要你当场批准**，并显示完整参数（包括要输入的文本）。「本对话内均允许」和「以后均允许」对它无效，因为每次的参数不一样，而参数本身就是风险。选了「完全访问权限」后不再逐次确认。
- **网页内容是外部不可信数据。** 页面里出现的任何指令都不是你的要求，助手不会照着执行。

:::

### 盒子本身

看盒子助手过去的对话、盒子的运行状态（连着的编辑器、素材导入任务、第三方 MCP、技能、备份），开关技能、重连第三方 MCP、续传或放弃卡住的导入、备份数据库。也可以在对话里帮你连接 Box Plan、接入你装好的第三方 MCP 服务。

恢复或删除备份、改盒子设置不在其内，要你在界面里自己做。

## 撤销与回滚

| 范围             | 怎么退回                                                                           |
| ---------------- | ---------------------------------------------------------------------------------- |
| **文件写入**     | 「本轮改动」里可以看 diff，见 [AI 对话 · 结果核对](/guide/assistant#结果核对-三层) |
| **生成的素材**   | 同名重新生成时，旧文件备份在 `.gdbox/history/`                                     |
| **资产库删除**   | 删掉的条目和文件夹可以恢复                                                         |
| **团队模式**     | 队员每交回一次改动了东西的活，盒子存一份项目快照，可以回滚到某一份；也可以恢复到冠军 |

::: warning 退不回来的几件事

- 普通对话里助手对项目文件的改动，盒子不存快照。项目最好放在版本控制下。
- shell 命令的效果。所以跑命令默认每次都要你确认，「自动批准」档也一样。
- 删笔记、删标签和合并标签，没有回收站。

:::

## 元能力

**沉淀技能和经验** —— 把验证过的做法写成可复用的技能，或修正被实际结果推翻的技能（引用了不存在的工具、某一步执行失败、结论被工具返回值否定）。工具报错后又改对了的做法，会被记成本项目的经验，再次出现相似的报错时附在后面。见[自动记录做法](/guide/tools-and-skills#自动记录做法)。

**提反馈** —— 任务结束且过程中确实有阻碍时，把问题整理成一份缺陷报告：卡在哪、绕行的代价、哪个工具表达能力不够、缺什么能力。报告写进文件，是否提交由你决定，**助手不会代为发送**。

触发方式：在对话里说「抱怨一下」、「刚才哪儿别扭」、「记下来提给开发者」。

**派子任务** —— 把界限清晰的一段活交给子任务，见[助手是怎么干活的 · 子任务](/guide/agent-loop#子任务)。

**组队** —— `/team` 把复杂任务交给分工的多个模型，见 [AI 对话 · 团队模式](/guide/assistant#团队模式)。

## 边界总表

跨领域的几条，无论问什么都成立：

| 边界                         | 具体是什么                                                       |
| ---------------------------- | ---------------------------------------------------------------- |
| **不碰编辑器缓存**           | `.godot/` 不改，`uid://` 不手造                                  |
| **不做美术与设计判断**       | 能核实事实，不评价好不好看、好不好玩                             |
| **听不见声音**               | 音频只能量数据，好不好听要你来听                                 |
| **改标记不等于做到**         | 改版本号、改配置里的声明不会让对应的事真的发生，做不到会直说     |
| **你明确要求的会照做**       | 技能里的限制是默认做法；你坚持时它说明一次风险，得到同意后执行   |
| **不代替你对外发送**         | 缺陷报告、网页上的提交动作、账号相关操作都停在你面前             |

# 出问题了

按症状找。找不到的话，日志在应用数据目录的 `logs/` 下，见[文件都放在哪](/guide/where-is-my-data)。

## AI 功能

### 界面提示「添加服务商，并选择『对话』默认模型后即可使用 AI」

还没配置模型。见[配置模型](/guide/ai-setup)。

### 「模型服务商返回『余额不足』」

**所配置服务商**的账户余额不足。到该服务商的控制台充值，或在 设置 → 模型 更换模型。

应用本身没有账户，不涉及应用的收费。

### 「API 密钥无效或已过期」

设置 → 模型，检查该服务商的密钥。复制时带了空格是最常见的原因。

### 「无法安全保存密钥，请通过环境变量提供密钥」

系统的加密存储不可用。把「API 密钥」改成填写环境变量名，或 `!` 开头的取密钥命令，见[密钥的三种填法](/guide/ai-setup#密钥的三种填法)。

### 测试连接失败

各条报错的含义见[测试连接失败](/guide/ai-setup#测试连接失败)。盒子自己发出的网络请求跟随系统代理，请求超时先确认代理设置。

### 订阅登录失败或反复要求登录

- Codex、Kimi Code、CodeBuddy / WorkBuddy 的令牌会自动续期。续期失败时，在 设置 → 模型 里点「重新登录」
- ZCode 没有刷新接口，令牌失效后必须重新登录
- 登录过程中提示平台要求重新验证（ZCode），先在 ZCode 官方页面完成验证，再回来重试
- 登录窗口长时间没动静，点「等待浏览器授权… 点此取消」重来。同一时间只能进行一次登录

### 「模型连接中断，N 秒后自动继续」

模型请求被中途掐断时，盒子会自动续跑，最多两次（间隔 10 秒、30 秒），已完成的步骤不会重复执行。

模型服务反复失败时，若 设置 → AI 助手 →「自动断点续传」开着（默认开），会每 60 秒从断点继续，连续失败 30 分钟后停止。服务商持续无响应的话，停止后换一个模型或渠道。

### 生图/视频类服务商测不了

这类接口调用即产生费用，所以不提供测试。界面会显示「连接测试会产生生成费用，因此不提供；首次生成时会验证配置」。**这不等于测通了** —— 第一次真用的时候才知道。

### 发送图片报错

主模型不支持识图，且没配「视觉」默认模型。换一个支持视觉的对话模型，或在 设置 → 模型 → 默认模型 → 视觉 指定一个。

### 「这条对话还有一轮在跑」

等它结束，或者直接在输入框发下一步的说明。不需要找「停止」再重发。

### 上下文满了

输入框附近的「上下文 X / Y」到顶会自动压缩。也可以手动 `/compact`。

无法压缩时会说明原因，见 [上下文窗口](/guide/assistant#上下文窗口)。

### 选了某个思考档位但没生效

提示「{模型} 没有 {所选} 这一档，本次实际按 {实际} 执行」。每个模型支持哪几档由它自己声明。

### Agent 说做完了，但实际没有

用「**审查**」重新查一遍，再查看「自证」回复，见[结果核对：三层](/guide/assistant#结果核对-三层)。

### 同一个操作试了几次就不试了

同一个工具、一字不差的同一组参数连续失败，会被拦下，防止 Agent 无限重发一个必然失败的调用：

- 一般工具：连续失败 2 次
- 检查项目、试玩、截图、执行命令这类结果随项目状态变化的工具：连续失败 5 次
- 中间只要有一次成功的写操作（改了文件、资产或项目），所有失败计数清零

换个说法让它用别的参数或别的路子重试即可。见[四道护栏](/guide/agent-loop#撞墙熔断)。

### 界面上显示「AI 锁定了 N 个文件」

Agent 修改一个文件时会锁住它，防止另一条对话同时改同一个文件。被挡的那条对话会收到「{文件} 正被「{对话}」修改，本次未改动」。点开指示器可以看到锁了哪些、被哪条对话锁着，旁边有「**全部解锁**」。

任务跑完锁会自动释放；应用进程崩溃后，锁表随之消失，不会留下残留的锁。见[文件锁](/guide/agent-loop#文件锁)。

### `/goal` 跑满轮数还没做成

目标模式默认最多迭代 10 轮，到顶就停下来交给你。目标确实需要更多轮的话，去 **设置 → AI 助手 →「目标模式最大轮数」** 调高（范围 1–50，下一条消息起生效）。

如果第一轮就停了并说验不了，那是 `BLOCKED` —— 审计员够不着要验的东西（例如这个目标交付的是一段回答而不是可查的状态）。这种情况再催多少轮都一样。见[目标模式](/guide/agent-loop#目标模式)。

### 敲了 `/goal` 但没进目标模式

对话挂在**只读**档时不进目标模式 —— 干活那一路什么都改不了，「只读」和「迭代到达成」本来就互斥。这一轮会按普通对话完整跑完，界面上会说一声。

### 拖进视频后，模型说看不到

- 对照[视频和音频](/guide/assistant#视频和音频)的三个条件：配好对象存储、模型勾了「视频」能力、走 OpenAI 兼容协议。缺一样，Agent 就会改用工具去看
- 时间线里有「传到对象存储失败」的提示的话，后面跟着原因。对象存储的各种报错见[对象存储 → 出问题了](/guide/object-storage#出问题了)
- 桶开了防盗链或 IP 白名单，厂商会下载失败

### 发送后报错，提到 video_url 或 input_audio

这家厂商支持视频，但不接受这种传法，或者不接受音视频和工具调用出现在同一个请求里。把完整报错发到 [GitHub Issues](https://github.com/ueboxai/gdbox/issues)。在那之前，可以先在「设置 → 模型」里取消这个模型的「视频」能力，退回用工具看视频。

## Godot 编辑器连接

### Agent 看不到编辑器里选中了什么

读写项目文件、检查报错、试玩和截图都不需要编辑器。看选中内容、场景树，在编辑器里打开场景、运行游戏，才需要编辑器连上盒子。按顺序查：

1. Godot 编辑器开着这个项目吗
2. 项目卡片上有没有「已连接」
3. 没有的话，项目卡片右键：显示「安装桥接插件」说明没装插件，点它装上
4. 装了还是没连上，到 Godot 的「项目设置 → 插件」里确认 GDBox Link 已启用

插件会自动连接，断开后每 3 秒重试一次，不需要手动操作。见[连接 Godot 编辑器](/guide/plugin#确认连上了)。

### 「Godot 编辑器连接服务未能启动」

盒子没能占用端口 `17870`，编辑器连不进来。横幅上会写原因：

- 「端口 17870 已被占用」：关掉占用该端口的程序或另一个 GDBox 窗口，点「重试」
- 「没有权限使用端口 17870」：重启 GDBox

### 导入项目时提示插件没装上

弹窗标题是「项目已导入，但 AI 连不上 Godot 编辑器」，正文写着原因。主按钮是「**交给 AI 排查**」，会新开一条对话，把项目路径和原因交给 Agent 去查。也可以事后从项目卡片右键 →「安装桥接插件」。

## 项目库

### 「没有找到 Godot 4」

Windows 上盒子会查 PATH、winget、scoop 和 Steam 的安装位置，其他系统只查 PATH 上的 `godot`。装在别处的，点「添加 Godot」选可执行文件，或把可执行文件、所在文件夹拖到引擎区域。

只认 Godot 4：Godot 3 或其他程序会提示「不是 Godot 4 可执行文件」。

### 打开项目时提示没有找到 Godot 4

打开项目、运行游戏、Agent 检查项目都要用到 Godot。到 设置 → 项目库 → Godot 编辑器 点「指定…」，或在项目库的引擎卡片上「设为默认」。

### 「读取项目列表失败」/「查找 Godot 失败」

**这次读取失败**，不代表没有项目或没装 Godot。点「重试」。

和「未找到匹配「xxx」的项目」不是一回事 —— 后者是搜索条件的问题，清空搜索框就好。

### 项目不在列表里

应用不扫描硬盘查找项目，需手动导入。点「我的项目」旁的 `+`，在弹窗里选 Godot 项目管理器里登记过的项目，或点「选择 project.godot 文件」；也可以把 `project.godot` 或项目目录直接拖进项目库。

装了 GDBox Link 的项目，在 Godot 里打开并连上盒子时会自动登记。

### 导入窗口里一个项目都没有

列表来自 Godot 项目管理器自己的项目名单。在 Godot 项目管理器里打开过项目之后再试，或者直接选 `project.godot` 文件。

### 两个同名项目，侧边栏里分成了两组

这是有意的。同名项目有不同路径时，侧边栏按路径拆开，对话发往各自路径对应的编辑器。名字只出现一次时仍合并为一组。

### 运行游戏后马上提示「游戏意外退出」

提示后面跟着日志里的报错。完整输出在项目的 `.gdbox/tmp/play.log`，可以让 Agent 读这个文件排查。

## 资产库

### 上传到共享库失败

先确认自己是不是只读身份。**没有写权限时上传按钮不是灰的，错误在上传时才返回。** 写权限由管理员开放。

### 「有 N 条改动待同步」

断网或服务器重启期间的正常状态。改动记在本地排队，恢复连接后自动推送。

「有改动无法同步到资产服务器，请检查冲突」是另一回事 —— 卡在版本冲突上了。

### 弹出「版本冲突」

多人修改了同一份索引。**选「覆盖远程版本」会丢弃对方的改动。**

### 导入卡在覆盖确认上

弹窗有倒计时，**超时按「跳过」处理**，那个文件不会导入。这是安全默认。

结束后的汇总里能看到跳过了哪些。

### 想重试失败的文件

在汇总中点「重试这 N 个文件」。提示「请切回原任务的资产库后重试」时需要切回原资产库；导入目标不随当前资产库变化。

### 直接往目录里放的文件库里看不到

用工具栏的「**扫描变更**」做一次增量扫描。

### 复制到项目时有文件没过去

「导入到项目」按原名把文件复制进项目里选定的文件夹，项目里已有同名文件的会跳过，不会覆盖。完成提示里会写跳过了几个。

### 「打开本地路径」打不开

提示会给出具体路径。网络库的话，去资产库设置里改「浏览路径」。

## 知识库

### 检索不可用

没配「嵌入」默认模型。设置 → 模型 → 默认模型 → 嵌入。

### 答得不准

用来源面板上的「**测试知识库召回率**」，看是没召回到，还是召回到了但没用好。结果里有匹配距离和关键词命中。

### 来源送不进去

上下文有预算上限。超出时会列出本次送不进去的来源，将其降为「只给摘要」或取消勾选即可。

### 网页内容不对

切到「**查看原文**」对一下。清洗失败时应用会明说是哪一种失败，不会假装成功，见[网页清洗](/guide/notebook#网页清洗)。

## 语音与录屏

### 麦克风读不到

「无法读取麦克风，请检查设备和权限」通常是系统层面没给麦克风权限。

### 配了语音还是用不了

「实时语音」是单独一类接口，**普通对话模型不适用**。目前支持 OpenAI `gpt-realtime` 系列和豆包 Seeduplex。

### 打断不了

默认是全双工的，**直接开口就能打断**。开口也没用的话，说明这会儿退化成半双工了 —— 本地朗读一条兜底通知时，或者回声消除通路没建起来时，麦克风会被强制静音。

这两种情况下只能手动打断：点界面上的球体，或在 设置 → 快捷键 给「打断语音助手」绑一个键（默认没绑）。

### 派了活之后它一直说「开始做了」

那句话是**派发回执**，不是执行结果。语音派活是非阻塞的 —— 派完就返回，你可以接着说话。真正的结果会在做完时另外念出来。

想知道进度就问「做得怎么样了」，它会报告所有任务线的进度。见[语音通话](/guide/voice#几件活同时跑)。

### 挂断再接上，之前派的活没人交代

会交代的。接上时它先念你不在期间攒下的事（做完的、失败的、还没人答的反问），一条都没有才一个字不说。

任务本身不受挂断影响，照跑。

### 「未检测到屏幕源」

先点「刷新屏幕源」。还是没有通常是系统没给屏幕录制权限。

### 找不到录屏入口

**侧边栏里没有录屏入口**。从资产库详情面板或 设置 → 录屏 打开，见[录屏与截图](/guide/small-tools)。

## 云盘

### 百度网盘授权失败

社区版不内置官方凭据，要先填自己的 AppKey 和 SecretKey。授权码**有效期 10 分钟**，过期就重新获取。

### 百度网盘传不了文件夹

从资产库右键上传这条路只支持单个文件。

### WebDAV 连不上

两种提示分别指向不同方向：「请检查服务器地址和凭据」是认证问题，「请检查网络和服务器配置」是连通性问题。

## 命令行

### 找不到 `gdbox` 命令

设置 → 命令行 → 点「加入 PATH」，然后**新开一个终端**。Linux 包不带命令行工具。

### 命令连不上

```bash
gdbox doctor
```

逐层报告断在哪。本机同时装了开发版和正式版时，用 `--config` 或 `GDBOX_HOST_CONFIG` 指定连哪一个。

### 写工具不在清单里

应用那头没开放写操作，多半是 设置 → MCP 里外部客户端的权限设成了只读。`gdbox doctor` 会说破。

### `editor_*` 工具用不了

没有连着的 Godot 编辑器。用 Godot 打开项目并启用 GDBox Link，见[连接 Godot 编辑器](/guide/plugin)。`godot_check`、`godot_run`、`godot_screenshot` 不需要编辑器。

### 退出码 7（超时）

请求可能已经到了盒子，结果不明。**不要直接重发** —— 先用只读工具确认当前状态。`ask` 超时说明它很久没有进度，不是跑得久。

## MCP

### 保存按钮点不动

有配置填写不完整，提示会说「有 N 条配置填写不完整」。常见的是标识为空、标识重复、环境变量格式不对。

### 外部客户端突然连不上

有人点过「重置令牌」。重置后所有客户端都要重新粘贴配置。

## 应用更新

### 检查更新说连不上

两条提示指向不同方向：「暂时无法获取更新，请稍后重试」是取不到更新清单，「暂时无法连接更新服务器，请检查网络后重试」是连不上。

更新源只有公开的 GitHub Releases，没有国内镜像。

### 一直没提示有新版本

如果这个安装包**没有配置更新源**（改过那个字段而没填新的源），它连一次检查请求都不发。见[更新源](/guide/install#更新源)。

### 侧边栏左下角有更新角标但装不了

角标在版本号右边，有三种状态：「新版本」（点击开始下载）、「下载中 N%」、「重启更新」（已下载完成）。

显示「重启更新」时点它，在确认框里选「立即重启」即可，安装会重启应用。如果 AI 仍有操作没做完，会先提示「AI 仍有 N 项操作正在进行」，选「仍然重启安装」会中断它们。

## 窗口与托盘

### 点关闭按钮后应用没有退出

关闭按钮只把主窗口隐藏到系统托盘，后台任务继续运行。要退出，用托盘菜单的「退出」。AI 仍有操作没做完时，会先弹出确认框，见[系统托盘](/guide/interface#系统托盘)。

### 托盘「最近项目」点了没反应

项目已经连上盒子（标「（运行中）」）或刚点过、插件还没连上（标「（启动中）」）时，菜单项不能再点，避免开出第二个编辑器。点击后打不开会弹系统通知，写明原因：项目文件不存在、项目已在 Godot 编辑器中打开，或「项目已打开，AI 连接失败」（插件没装上，点通知查看原因）。

### 开机自启关不掉

设置 → 常规 →「开机自启」默认关闭，关闭之后盒子不会再自行改回开启。如果仍然随系统启动，检查系统自己的启动项设置。

## 提问题

带上日志到 [GitHub Issues](https://github.com/ueboxai/gdbox/issues)。

也可以在 AI 对话中说「抱怨一下」「记下来提给开发者」，Agent 会将本次遇到的问题写成一份缺陷报告文件，是否提交由你决定。

# GDBox：从虚幻盒子分叉迭代

> 状态：进行中（2026-10-14 开始）。
> 前身：从零写的 GDBox 原型，设计稿见 [GDBox原型设计-2026-10-14.md](GDBox原型设计-2026-10-14.md)，代码留在本机 `H:\UnrealAgent\_gdbox-v0`（不发布）。

## 为什么换路子

原型是从零写的：只有 6 个组件、只抄了配色，界面和交互跟虚幻盒子对不上。用户要的是**同一家公司的两条产品线**：设计语言统一，外壳、交互、组件一致，只是面向的引擎不同。

所以改成：

1. 把虚幻盒子源码（uebox-pub `b6b4aab`）整体复制过来，作为第一个提交；
2. 删掉虚幻专属的内容；
3. 原有外壳和交互保留，迭代成 Godot 版；
4. 原型里已经跑通的 Godot 能力，作为模块迁进来。

「脱钩」指运行时不依赖虚幻盒子的配置和数据，不是不复用代码。

## Agent 底层

虚幻盒子的 agent-v3 本来就建在 pi 上（`@earendil-works/pi-agent-core` + `pi-ai`），不是自研内核。所以「用最新的 pi」落实为**把 pi 升到最新版本**（1.0.0 → 1.2.0），而不是推倒重写。界面和 Agent 之间的协议（`agent-v3:*` IPC、`AgentV3Event`）一个字不动。
